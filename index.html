📖 如何获取 GitHub Token

📌 步骤 1：登录 GitHub
访问 https://github.com/login 登录你的账号
📌 步骤 2：进入 Token 设置
点击右上角头像 → Settings → 左侧菜单 Developer settings → Personal access tokens → Tokens (classic)
📌 步骤 3：生成新 Token
点击 Generate new token (classic)，填写备注（如 "pokedex"），
必须勾选 repo 权限
📌 步骤 4：复制 Token
点击底部 Generate token，⚠️ 立即复制并保存！
Token 格式：ghp_xxxxxxxxxxxxxxxxxxxx
💡 重要提示
Token 只能看到一次，丢失需重新生成！
请将 Token 填写到配置中，不要上传到公开仓库！
